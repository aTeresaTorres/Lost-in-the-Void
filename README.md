# Lost in the Void

Sitio web del libro *Lost in the Void*. Por ahora es un **coming soon** con un avance del 7%, más una sección de **spoilers** con las fichas de los personajes.

## Cómo verlo localmente

Abre `index.html` en el navegador. No necesita servidor ni build.

## Cómo agregar un capítulo

1. Crea `chapters/chapter-XX.html` reutilizando `../css/base.css`.
2. Sube los banners a `img/banners/` (ej. `chapter-01-banner-01.png`).
3. Los banners van a todo el ancho, sin márgenes.
